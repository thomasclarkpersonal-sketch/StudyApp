# A19 · Acceptance Scenarios

Owner: QA & Test Engineer / Systems Analyst. Stage 2, written 2026-10-21. Catalog entry: A19.

This document specifies the **137 Given / When / Then acceptance scenarios (`AT-001`–`AT-137`)** verifying the **Study App & Generation Pipeline**.
- **Complete UC coverage (`G2.3`, `A19.1`):** Every Use Case main success scenario (`UC-01`–`UC-21`, `AT-001`–`AT-021`) and every Use Case extension (45 extensions across `UC-01`–`UC-21`, `AT-022`–`AT-050` and `AT-099`–`AT-114`) has a dedicated scenario.
- **Complete Decision Table rule coverage (`G2.4`, `A19.1`):** Every complete rule before reduction (`DT-01-C1`..`C8` through `DT-06-C1`..`C8`, 48 rules total) has a dedicated scenario (`AT-051`–`AT-098`).
- **Complete Requirement & Metric coverage (`G2.1`, `G2.15`, `A19.3`):** Every functional requirement (`REQ-F-001`–`REQ-F-066`), every non-functional requirement (`REQ-N-001`–`REQ-N-023`, `AT-115`–`AT-137`), and every `A01` success metric (`SM-1`–`SM-6`) traces to one or more scenarios.
- **Observable outputs (`A19.2`):** Every `Then` clause specifies an observable UI screen state, CLI output, exported file, report, or HTTP response payload rather than internal database inspection alone.
- **CSV companion (protocol §5.3):** The full 137-row table is stored in [`acceptance-scenarios.csv`](acceptance-scenarios.csv) beside this file, and split into 5 sections of <= 39 rows below.
