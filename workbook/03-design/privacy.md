## 1. Privacy Context, Roles, and Applicable Framework

1. **Single Data Subject and Data Controller (`[SEED §2]`, `[SEED §4]`, `ASM-021`):**
   - The system is a personal study application built for and operated by **one university student** (`Student` at HKUST, Hong Kong SAR).
   - There are no accounts for other people, no multi-tenant sharing (`MT` not set), and no special-category data (no health, biometric, financial payment, or children's data; `FIN` and `REG` not set, `ASM-033`, `ASM-034`).
2. **Prohibition on Third-Party Personal Data (`[SEED §4]`, `DEC-008`, `ASM-049`, `REQ-N-016`):**
   - Course syllabi (`SRC-05`) and HKUST Canvas pages contain third-party personal data (lecturer and teaching-assistant names, email addresses, office locations, and other students' Canvas posts).
   - **Data-minimization rule (`BR-002`):** The Canvas adapter (`M09` `CLI-01`, `ADR-005`) never requests `/users`, `/enrollments`, `/discussion_topics`, or `/submissions`, and strips author/instructor PII fields (`user_name`, `author`, `email`, `avatar_url`) before writing to `<workspace>/source/canvas/`. The Extractor prompt (`M11`) explicitly ignores staff contact details.
3. **Legal Basis (Hong Kong PDPO Cap. 486 DPP1–DPP6 & GDPR / UK GDPR Reference):**
   - Where data-protection law applies, the student processes their own personal study data for personal academic study (domestic/personal-use exemption and self-consent / performance of user-requested service, GDPR Art. 6(1)(a)/(b), HK PDPO DPP1/DPP3).
   - University permission to send course material and study prompts to Anthropic's Claude API is confirmed (`[USER Q-01]`, `ASM-002`), and no course material or personal study data is ever sent to any third party other than Anthropic (`[SEED §10]`).

## 4. Data-Subject Request Procedures (Access, Correction, Deletion, Export)

Because the student is the sole user and operator (`ASM-021`), all four data-subject rights are self-service through the UI (`A35`) and CLI (`A34`):

1. **Right of Access & Portability (Export):**
   - **Full SQLite snapshot:** `[Create Verified SQLite Backup Now]` on `SCR-10` (`POST /api/backup/create`) produces a complete, self-contained SQLite file (`study.db`).
   - **Structured JSON / TSV / Calendar exports:** `[Export feedback.json]` (`GET /api/export/feedback`, `RPT-08`), `[Download calendar.ics]` (`GET /api/calendar.ics`, `RPT-07`), `[Export Anki TSV]` (`GET /api/export/anki.tsv`, `RPT-09`), and `<workspace>/export/*.json` (`RPT-08`).
2. **Right to Rectification (Correction):**
   - Cards can be edited in place (`PATCH /api/cards/{cardId}`, `SCR-02`); quiz ratings can be overridden (`PATCH /api/quiz/attempts/{attemptId}`, `SCR-03`); deadlines, milestones, readings, tasks, and settings can be edited on `SCR-05`, `SCR-01`, and `SCR-10`.
3. **Right to Erasure (Deletion):**
   - **Single Tutor Thread:** `[Delete Thread]` on `SCR-07` (`DELETE /api/tutor/threads/{threadId}`) permanently deletes the thread and all its messages (`REQ-F-052`, `ASM-023`).
   - **Pipeline Intermediate Files:** `pipeline-cli clean-rounds --module <id>` (`CLI-07`) permanently deletes all draft and review-round files (`*.round*.json`, `reviewer-input.r*.json`) at the end of a module (`REQ-N-017`, `ASM-024`).
   - **Full Database Erase:** Deleting `study.db` and `backups/*.db` on the local filesystem (or destroying the Fly.io volume in `R3`) permanently erases 100% of stored personal data.

## 5. Data-Minimization Decisions (`A37`)

1. **Zero User Account PII:** No name, email address, student ID number, phone number, or IP address is stored in `study.db` (`R33` `auth_session` stores only a hashed session token and a coarse `user_agent` summary).
2. **Zero Third-Party PII from Canvas or Syllabi:** `CanvasClient` (`M09`) blocks roster/discussion endpoints and strips staff/author names and emails before writing to disk (`ADR-005`, `DEC-008`, `REQ-N-016`).
3. **Redacted Application Logs (`A38`):** Structured logs never record flashcard text, student written answers, tutor chat messages, passwords, or API tokens (`REQ-N-012`, `REQ-N-013`, `REQ-N-016`).
4. **Scoped Ephemeral Prompt Context:** Tutor and marking calls send only the active module's glossary and the cited lecture slides (`REQ-F-047`), never unrelated modules or full database dumps.
